03 / GET STARTED

三步，开始使用。

DSH Mobile 连接你自己的主机，不内置 Host。

01

准备 Host

确保已有 DSH Host 0.2.1 或更高版本，并让手机能够访问它。

dsh web --host <IP> --port 3080
02

配对连接

安装应用后，使用配对链接或扫码连接你的 Host。

03

开始使用

查看任务、参与会话，在需要时审批和评审变更。
